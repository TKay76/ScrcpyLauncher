============================================================
  Scrcpy Launcher v1.0  (Windows 10 / 11)
============================================================

[설치 및 실행 방법]
1. 공식 scrcpy(Windows 64-bit)를 다운로드하여 압축을 풉니다.
   https://github.com/Genymobile/scrcpy/releases
2. 압축을 푼 폴더(scrcpy.exe, adb.exe가 있는 폴더) 안에
   ScrcpyLauncher.exe 파일을 복사한 뒤 더블클릭하여 실행합니다.
   (별도 런타임 설치 없이 Windows 10/11에서 바로 실행됩니다.)

[스마트폰 최초 설정 (1회만)]
1. 설정 → 휴대전화 정보 → 소프트웨어 정보 → '빌드번호' 7번 연속 터치
2. 설정 → 맨 아래 '개발자 옵션' → 'USB 디버깅' 켜기
3. USB 케이블로 PC와 연결 후 폰 화면의 'USB 디버깅 허용' 팝업에서 허용
   (무선 사용 시: USB 연결 상태에서 런처의 [유선 → 무선] 버튼 클릭)

[주요 기능]
- USB 유선 자동 감지 및 Wi-Fi 무선 원클릭 전환 (유선 → 무선)
- 수동 무선 디버깅 페어링 / IP 직접 연결
- ADB 문제 해결 (무선 연결 해제 / ADB 서버 재시작)
- 코덱(H.264/H.265/AV1), 비트레이트, 해상도, 렌더러, 저지연(low-latency),
  UHID 게임패드, 폰 화면 끄기 등 세부 옵션 및 실시간 마우스 오버 가이드
- 가상 디스플레이(--new-display) 및 설치된 앱 목록 자동 불러오기/검색/바로 실행
- 화면 캡처(.png) 및 미러링을 끊지 않는 원클릭 화면 녹화(.mp4)
- 미러링 창 좌측 상단 클릭 통과 투명 FPS 오버레이
- 마지막 설정 자동 저장 (scrcpy_launcher_settings.json)

[실행 중 주요 단축키]
- Alt + F         : 전체화면 전환
- Alt + O         : 스마트폰 화면 끄기 (미러링 유지)
- Alt + Shift + O : 스마트폰 화면 다시 켜기
- Alt + I         : FPS 오버레이 켜기 / 끄기
- Alt + H / B / S : 홈 / 뒤로 가기 / 최근 앱
- Alt + R         : 화면 회전
- Alt + ↑ / ↓     : 볼륨 조절
