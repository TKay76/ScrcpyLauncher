============================================================
  Scrcpy Launcher v1.3.5  (Windows 10 / 11)
============================================================

[설치 및 실행 방법]
1. 공식 scrcpy(Windows 64-bit)를 다운로드하여 압축을 풉니다.
   https://github.com/Genymobile/scrcpy/releases
2. 압축을 푼 폴더(scrcpy.exe, adb.exe가 있는 폴더) 안에
   ScrcpyLauncher.exe 파일을 복사한 뒤 더블클릭하여 실행합니다.
   (기존 v1.0.0 사용자는 덮어쓰기하면 기존 설정이 유지됩니다.)

[스마트폰 최초 설정 (1회만)]
1. 설정 → 휴대전화 정보 → 소프트웨어 정보 → '빌드번호' 7번 연속 터치
2. 설정 → 맨 아래 '개발자 옵션' → 'USB 디버깅' 켜기
3. USB 케이블로 PC와 연결 후 폰 화면의 'USB 디버깅 허용' 팝업에서 허용
   (무선 사용 시: USB 연결 상태에서 런처의 [유선 → 무선] 버튼 클릭)
   ※ 가상 디스플레이 실행 시 게임이 튕기면 개발자 옵션 맨 아래
      '활동 크기 조정 가능(활동을 크기 조절 가능하게 강제 설정)'을 켜주세요!

[클래식 모드 기본 조작법 (1920x1080/280 · 2560x1440/373 기준)]
- W / A / S / D  : 이동 (Shift 함께 누르면 전력질주)
- Alt            : 마우스 시점 회전 모드 ON / OFF (커서 잠금 토글)
- 마우스 좌/우클릭 : 일반 공격(꾹 누르면 차지) / 특수 공격 (시점 모드 ON 시)
- Space          : 회피
- Q / E / R      : 특수 / 기술 / 동료 오의
- 1 / 2 / 3 / 4  : 오의 1번 · 우측 슬롯 2~4
- F / C / G / X  : 상호작용 / 아이템 빠른 사용 / 아이템 선택 / 취소
- M / ESC / ` / J: 지도 / 메뉴 / 건너뛰기 / 구출

[실행 중 주요 단축키]
- F1              : 키 매핑 화면 힌트 켜기 / 끄기
- F2              : 채팅 모드 토글 (한글 입력 일시정지 / 재개)
- Ctrl + F1 ~ F9  : 키 매핑 프로파일 즉시 전환 (무기별 전환)
- Alt + F         : 전체화면 전환
- Alt + O         : 스마트폰 화면 끄기 (미러링 유지)
- Alt + Shift + O : 스마트폰 화면 다시 켜기
- Alt + I         : FPS 오버레이 켜기 / 끄기
- Alt + H / B / S : 홈 / 뒤로 가기 / 최근 앱
- Alt + R         : 화면 회전
- Alt + ↑ / ↓     : 볼륨 조절
