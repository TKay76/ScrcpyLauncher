# HuntLink v2.0 (Scrcpy Launcher)

**몬스터헌터 아웃랜더스(Monster Hunter Outlanders)**를 포함한 Android 게임을 Windows PC에서 초저지연으로 플레이할 수 있는 [scrcpy](https://github.com/Genymobile/scrcpy) 기반 컴패니언 런처입니다.

복잡한 명령어나 배치 파일 없이 클릭만으로 **유선·무선 미러링, 16:9 / 21:9 가상 디스플레이, 초저지연 멀티터치 키 매핑, 게임패드, 긴급 퀘스트 동시 클리어 플래너(`F7`/`F8`), 몬스터 도감(39종), 미니 한글 채팅창(`F2`), 실시간 연결 속도·배터리 온도 모니터링**까지 한 번에 사용할 수 있습니다.

*(기존 `Scrcpy Launcher` 사용자분들은 실행 파일명 `ScrcpyLauncher.exe`가 동일하므로 앱 내 원클릭 자동 업데이트로 바로 v2.0으로 업그레이드할 수 있습니다.)*

---

## 주요 기능 (v2.0)

### 1. 홈 · 실행 & 원클릭 프리셋
- **조작 모드 3분할 원클릭 전환**
  - **키보드 + 마우스 (키 매핑)**: `scrcpy` 입력 충돌 자동 차단 + 미러링 시작 시 키 매핑 자동 연결
  - **게임패드 (Xbox / PS)**: UHID 물리 컨트롤러(`-G`) 자동 활성화 + 우클릭 뒤로가기 충돌 방지 + 선택적 키보드 보조 매핑
  - **일반 미러링**: 일반 마우스·키보드 조작 및 영상 시청
- **화면 · 성능 원클릭 프리셋 4종**
  - **추천 1080p**: 유선 폰·폴더블 추천 (`H.264 · 20Mbps · 가상 1920x1080/280 · DeX 건너뛰기`)
  - **고화질 1440p**: 플래그십 기기 + QHD/4K 모니터 추천 (`H.265 · 20Mbps · 가상 2560x1440/373`)
  - **기기 본체 화면**: 태블릿(갤럭시 탭·Y700 등) 추천 (가상 디스플레이 OFF로 PC모드/DeX 전환 방지 + `Alt+O` 완벽 지원)
  - **무선 안정**: Wi-Fi 무선 추천 (`H.265 · 12Mbps · 오디오 안정화 120ms ON`)
- **실시간 연결 속도 · 배터리 온도 배지**
  - 유선 USB 협상 속도(`USB 3.2 Gen 1/2` vs `USB 2.0 480Mbps` + 케이블/포트 업그레이드 진단) 및 무선 Wi-Fi 대역·속도(`5GHz/2.4GHz · Mbps`) 실시간 표시
  - 기기 배터리 잔량(`%`)·충전 상태·온도(`°C`) 15초 자동 갱신 및 고온 주의 색상 표시
- **창 모드 실시간 동적 제목표시줄 HUD**
  - 별도 오버레이 없이 미러링 창 제목표시줄에 `[활성 키매핑 프로파일] | FPS | 배터리·온도 | 1순위 추천 퀘스트`를 실시간 표시 (스터터링·지연 0%)
- **자주 쓰는 빠른 옵션**: 폰 화면 끄기(`-S`), 전체화면 시작(`-f`), 실시간 **항상 위에**, **창 위치·크기 기억**, **오디오 안정화(`--audio-buffer=120`)**
- **유선(USB) + 무선(Wi-Fi) 통합 관리**: 일련번호 자동 마스킹, 원클릭 **`[유선 → 무선]`** 전환, 수동 무선 페어링, **`[무선 해제]`** / **`[ADB 재시작]`**

### 2. 초저지연 멀티터치 키 매핑 (`키 매핑` 탭)
- **상용 앱플레이어급 고정 슬롯 멀티터치 엔진**: `scrcpy-server` 제어 소켓 직결로 `WASD` 즉시 반응 이동 + `Shift` 질주 + 마우스 360° 시점 회전(Win32 Raw Input) + 좌/우클릭 공격·보조 + 스킬 동시 입력 지원
- **조합키 & 마우스 확장 버튼**: `Ctrl` / `Shift` / `Alt` + 키보드 키, 마우스 4·5·휠클릭 지원
- **휠 드래그 키 타입**: `Tab`(부위 조준) · `G`(아이템/탄환 휠) 등 키를 누른 채 마우스로 방향 선택 지원
- **무기별 프로파일 관리 & 공유**: `Ctrl + F1 ~ F9` 실시간 전환, 한 줄 공유 코드(`SLKM2:...`), LD플레이어 `.kmp` 불러오기
- **`[화면에서 키 배치]`** 드래그 앤 드롭 편집 · **`F1`** 키 힌트 토글 · 힌트 투명도/크기 슬라이더

### 3. 긴급 퀘스트 동시 클리어 플래너 (`퀘스트 플래너` 탭)
- **`F7` 왼쪽 퀘스트 목록 일괄 스캔**: 화면에 보이는 퀘스트(7~8개)를 한 번에 수집하고, 스크롤 후 한 번 더 누르면 **LCS 순서 정렬 병합**으로 위·중간·아래 어느 위치에 새 퀘스트가 추가되더라도 중복 없이 정확히 `10/10`을 정리합니다.
- **`F8` 개별 퀘스트 수집 & 자동 학습**: 선택한 퀘스트 1건을 정밀 OCR해 수집하며, 미등록 신규 퀘스트는 로컬 DB(`quest_title_db.json`)에 자동 학습됩니다.
- **42종 긴급 퀘스트 내장 DB** · 지역/종족/포획·사냥/무기 조건 교차 분석으로 **동시 클리어 최적 동선 추천**
- 일일 완료 카운터 (매일 오전 5시 KST 자동 초기화) 및 보유 퀘스트 자동 저장(`quests_active.json`)

### 4. 몬스터 도감 · 서식지 빠른 검색 (`몬스터 도감` 탭)
- 4개 위키 교차 검증 **39종 몬스터(일반/아종/융광종)** 서식지·종족 빠른 검색 및 지역/종족 필터링
- *(추후 웹 연동 기능으로 몬스터별 상세정보 페이지 추가 예정)*

### 5. 고급 설정 · 편의 기능 (`고급 설정` 탭)
- **미니 한글 채팅창 (`F2`)**: 키매핑·패드·일반 전 모드에서 한글 입력 후 `Enter`로 즉시 게임 채팅 전송
- **즉시 스크린샷 (`F12` / Xbox Share)**: `.png` 저장 + 클립보드 자동 복사
- **무중단 백그라운드 녹화 (`.mp4`)** · **순정 `scrcpy` 추가 옵션 직접 입력** · **접이식 실시간 로그**
- **3개국어 지원**: 한국어 / English / 日本語
- **원클릭 자동 업데이트**: GitHub Releases 새 버전 출시 시 클릭 한 번으로 다운로드·교체·재실행

## 설치 및 시작 방법

1. 공식 **scrcpy (Windows 64-bit)**를 다운로드하여 압축을 풉니다.
   - https://github.com/Genymobile/scrcpy/releases
2. [Releases 페이지](https://github.com/TKay76/ScrcpyLauncher/releases)에서 **`ScrcpyLauncher.exe`**를 다운로드합니다.
3. 압축을 푼 `scrcpy` 폴더(`scrcpy.exe`, `adb.exe`가 있는 곳)에 `ScrcpyLauncher.exe`를 넣고 더블클릭하면 바로 실행됩니다.
   - Windows 10 / 11 기본 내장 .NET Framework 4.8 기반으로 별도 런타임 설치가 필요 없습니다.
4. 스마트폰을 연결하면 **몬스터헌터 아웃랜더스 앱이 자동으로 선택**됩니다.
   - 자동 선택되지 않았거나 다른 앱을 실행하려면 좌측 **`[고급 설정]` → `실행 앱`**에서 원하는 앱을 선택해 주세요. *(가상 디스플레이 + DeX 건너뛰기 사용 시 실행 앱을 선택해야 검은 화면이 뜨지 않습니다.)*

> ⚠️ **최초 실행 시 Windows 보호 창이 뜰 경우**
> 개인 빌드 실행 파일 특성상 Windows SmartScreen 경고가 나타날 수 있습니다. **`[추가 정보]` → `[실행]`**을 눌러 진행해 주세요.

## 실행 중 주요 단축키

| 단축키 | 기능 | 비고 |
| :--- | :--- | :--- |
| **`Alt`** | 시점 회전 모드 ON / OFF | 커서 잠금·해제 토글 (`키 매핑` 탭에서 변경 가능) |
| **`F1`** | 화면 키 힌트 켜기 / 끄기 | 투명도·크기 조절 지원 |
| **`F2`** | 미니 한글 채팅창 열기 | 한글 입력 후 `Enter`로 즉시 전송 (전 모드 지원) |
| **`F7`** | 긴급 퀘스트 왼쪽 목록 일괄 스캔 | 스크롤 후 재입력 시 자동 중복 제거 (LCS 병합) |
| **`F8`** | 선택한 퀘스트 1건 수집 및 자동 학습 | 우측 상세창 정밀 OCR + 로컬 DB 자동 학습 |
| **`F12` / Xbox Share** | 즉시 스크린샷 저장 (`.png`) | 클립보드 자동 복사 |
| **`Ctrl + F1 ~ F9`** | 무기별 키 매핑 프로파일 즉시 전환 | 화면 상단 토스트 + 제목표시줄 즉시 반영 |
| **`Alt + F`** | 전체화면 전환 | |
| **`Alt + O` / `Alt + Shift + O`** | 스마트폰 화면 끄기 / 켜기 | |
| **`Alt + I`** | 실시간 FPS 표시 켜기 / 끄기 | |

## 직접 빌드하기 (Windows)

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```
Windows 기본 내장 `csc.exe`(.NET Framework 4.8)로 별도 SDK 설치 없이 즉시 빌드됩니다.
