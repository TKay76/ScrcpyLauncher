# Scrcpy Launcher

Windows용 [scrcpy](https://github.com/Genymobile/scrcpy) 유선·무선 Android 미러링 & 멀티터치 키 매핑 GUI 런처입니다.
복잡한 명령어나 배치 파일 없이 클릭만으로 기기 연결, 가상 디스플레이(16:9), 키보드·마우스 멀티터치 매핑, 게임패드, 화면 캡처·녹화, 실시간 투명 FPS 오버레이까지 사용할 수 있습니다.

---

## 주요 기능

- **조작 모드 3분할 원클릭 전환**
  - **키보드 + 마우스 (키 매핑)**: `scrcpy` 입력 충돌 자동 차단 + 미러링 시작 시 키 매핑 자동 연결
  - **게임패드 (Xbox / PS)**: UHID 물리 컨트롤러(`-G`) 자동 활성화 + 우클릭 뒤로가기 충돌 방지
  - **일반 미러링**: 일반 마우스·키보드 조작 및 영상 시청
- **초저지연 멀티터치 키 매핑 (`키 매핑` 탭)**
  - `scrcpy-server` 제어 소켓 직결로 `WASD` 이동 + `Shift` 전력질주 + 마우스 360° 시점 회전(Win32 Raw Input) + 좌/우클릭 공격 + 스킬 동시 입력 지원
  - 기본 내장 프리셋: **`몬헌 아웃랜더스 (클래식 모드)`**, **`몬헌 아웃랜더스 (스타팅 모드)`**
  - **LD플레이어 `.kmp` 파일 바로 불러오기** 및 사용자 프로파일 저장
  - **`[화면에서 키 배치]`** 드래그 앤 드롭 편집 & 게임 중 **`F1`** 반투명 키 힌트 토글
- **유선(USB) + 무선(Wi-Fi) 통합 지원**
  - USB 기기 자동 감지, 원클릭 **`[유선 → 무선]`** 전환, 수동 무선 페어링, **`[무선 해제]`** / **`[ADB 재시작]`**
  - 미러링 시작 시 자동 화면 깨우기(`KEYCODE_WAKEUP`) 지원
- **가상 디스플레이 & 앱 바로 실행**
  - **`1920x1080/280`** (FHD 추천) / **`2560x1440/373`** (QHD 고화질) — 두 해상도 간 UI·키 배치 비율 100% 일치
  - `DeX / 시스템 UI 건너뛰기` + 설치된 사용자 앱 목록 자동 불러오기 및 검색
- **화면 캡처 · 녹화 · 투명 FPS 오버레이**
  - **`[화면 캡처]`** (`.png`) & 미러링을 끊지 않는 백그라운드 **`[● 녹화 시작 / 중지]`** (`.mp4`)
  - 미러링 창 좌측 상단 클릭 통과 투명 FPS 카운터
- **자동 업데이트 알림**: GitHub Releases 새 버전 출시 시 상단에 업데이트 버튼 자동 표시

## 설치 및 사용 방법

1. 공식 **scrcpy (Windows 64-bit)**를 다운로드하여 압축을 풉니다.
   - https://github.com/Genymobile/scrcpy/releases
2. [Releases 페이지](https://github.com/TKay76/ScrcpyLauncher/releases)에서 **`ScrcpyLauncher.exe`**를 다운로드합니다.
3. 압축을 푼 `scrcpy` 폴더(`scrcpy.exe`, `adb.exe`가 있는 곳)에 `ScrcpyLauncher.exe`를 넣고 더블클릭하면 바로 실행됩니다.
   - Windows 10 / 11 기본 내장 .NET Framework 4.8 기반으로 별도 런타임 설치가 필요 없습니다.

> ⚠️ **최초 실행 시 Windows 보호 창이 뜰 경우**
> 개인 빌드 실행 파일 특성상 Windows SmartScreen 경고가 나타날 수 있습니다. **`[추가 정보]` → `[실행]`**을 눌러 진행해 주세요.

## 클래식 모드 기본 조작 매뉴얼 (`1920x1080/280` · `2560x1440/373`)

| 키 | 기능 | 비고 |
| :--- | :--- | :--- |
| **`W / A / S / D`** | 캐릭터 이동 | 8방향 부드러운 조이스틱 이동 |
| **`Shift`** (길게) | 전력질주 | 이동 중 함께 누르면 대시 |
| **`Alt`** | 시점 회전 모드 ON / OFF | 커서 잠금·해제 토글 (`키 매핑` 탭에서 `` ` `` / `Tab` 변경 가능) |
| **마우스 좌/우클릭** | 일반 공격(차지) / 특수 공격 | 시점 회전 모드 ON 시 작동 |
| **`Space`** | 회피 | 우측 하단 회피 버튼 |
| **`Q` / `E` / `R`** | 특수 / 기술 / 동료 오의 | |
| **`1` `2` `3` `4`** | 오의 1번 · 우측 슬롯 2~4 | |
| **`F` / `C` / `G` / `X`** | 상호작용 / 아이템 빠른 사용 / 아이템 선택 / 취소 | |
| **`M` / `ESC` / `` ` `` / `J`** | 지도 / 메뉴 / 건너뛰기 / 구출 | |
| **`F1`** | 화면 키 힌트 켜기 / 끄기 | 런처 편의 단축키 |

## 직접 빌드하기 (Windows)

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```
Windows 기본 내장 `csc.exe`(.NET Framework 4.x)로 별도 SDK 설치 없이 즉시 빌드됩니다.
